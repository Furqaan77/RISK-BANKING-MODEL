# 07. Glossary (plain English)

| Term | Meaning |
|---|---|
| **On-prem** | Runs on the bank's own computers, not in our cloud |
| **CBUAE** | Central Bank of the UAE |
| **Fed / OCC / CFPB** | US regulators: Federal Reserve; Office of the Comptroller of the Currency (national banks); Consumer Financial Protection Bureau (consumer lending rules) |
| **PRA / FCA / BoE / FPC** | UK: Prudential Regulation Authority (bank safety); Financial Conduct Authority (conduct, consumers); Bank of England; its Financial Policy Committee |
| **AECB** | Al Etihad Credit Bureau (UAE credit scores) |
| **DBR / DTI** | Debt-burden ratio (UAE) / debt-to-income (US): monthly debt payments ÷ income |
| **LTV** | Loan-to-value: loan ÷ property value |
| **LTI** | Loan-to-income: mortgage ÷ annual income (UK) |
| **DSCR** | Debt-service coverage: business cash flow ÷ loan payments (above 1 means it can pay) |
| **ATR / QM** | US mortgage rules: Ability-to-Repay; Qualified Mortgage |
| **NPL / NPF** | Non-performing loan / financing (Islamic term): a loan that has stopped paying, usually 90+ days late |
| **IFRS 9 staging** | Accounting stages for loans: 1 normal, 2 worse (e.g. 30+ days late), 3 defaulted (90+) |
| **PD / LGD / EAD / EL** | Chance of default / share lost if it defaults / amount owed at default / expected loss = PD × LGD × EAD |
| **Single-borrower / large-exposure limit** | The most a bank may lend to one customer or connected group (~25% of Tier 1 capital) |
| **Tier 1 capital** | The bank's core capital (mainly shareholders' equity) |
| **Finance house / finance company** | A non-bank lender (e.g. gold loans, cash finance, consumer finance) |
| **SME** | Small and medium enterprise |
| **BNPL** | Buy now, pay later |
| **Murabaha / Ijara** | Islamic finance: cost-plus sale / lease |
| **AAOIFI** | The Islamic finance standards body |
| **Tighten-only** | A lower rule layer may only be stricter than the layer above |
| **Maker-checker** | One person proposes a change, a second approves it |
| **Refer** | Send to a human underwriter |
| **Master rulebook** | Our organised list of each central bank's hard limits |
| **Too rigid / Higher risk** | A bank is stricter (missing customers) / looser (taking risk) than its peer median |
| **BMAD** | The planning method and agent toolkit installed in `_bmad/` |
| **Skeleton / organs** | The working shape of the platform now / the real models, data and UI added later |
